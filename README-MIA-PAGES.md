## GitHub Pages

The repository includes a GitHub Actions Pages workflow in `.github/workflows/mia-pages.yml`.

For the `github.io` URL to serve, GitHub repository Settings → Pages must use **GitHub Actions** as the publishing source. The workflow is already committed.
