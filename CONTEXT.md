# Mia Media Library CONTEXT

One job: store and organize reusable media for the Mia site, demos and approved marketing materials.

## Inputs
- Asset inventory: [README](README.md)
- Public site: [Mia site](https://github.com/MohammedAbdelshafy/mia-ai-site)
- Customer language rules: [Jarvis ICM language guide](https://github.com/MohammedAbdelshafy/jarvis-mbm/blob/feature/icm-portfolio-map/ICM/_shared/customer-language.md)

## Process
1. Identify where an asset is used before renaming or moving it.
2. Keep current filenames/URLs stable unless all consumers are updated.
3. Mark simulated demo footage and planned capability accurately.
4. Check rights, voice/image permissions and intended use before external publication.
5. Prefer links to the canonical asset instead of duplicate uploads.

## Output
A maintained, linkable media library with clear names and known consumers.

## Check
A cold reader can find the asset, confirm the page that uses it, and distinguish an illustrative animation from a real live product action.
