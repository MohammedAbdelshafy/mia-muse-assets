# Mia Muse Assets

A library of clips, images, audio and demo assets used by the Mia site and related product explainers. Keep asset paths stable and label simulated product footage accurately.

- `mia-hi.mp4` — Mia's 10-second video greeting
- `mia-hi-voice.mp3` — the voice line
- `mia-hi-thumb-base.jpg` — base thumbnail
- `thumbs/hi-b01_*.jpg` — personalized "Hi {name}!" thumbnails, batch 01

## Mia teaches

Teaching videos presented by Mia as a social teaching persona ("Professor Mia" — a social label only, not a product). These are AI-presented teaching explainers, not recordings of live product actions. All four episodes below are lip-synced to their voiceovers (local lip-sync pass).

- `mia-teaches-antigravity-final.mp4` — Google's agentic IDE: agents plan, write code, and show changes for review. https://mohammedabdelshafy.github.io/mia-muse-assets/mia-teaches-antigravity-final.mp4
- `mia-teaches-v2-talorys-final.mp4` — Your own AI assistant inside your own Cloudflare account, not a vendor's server. https://mohammedabdelshafy.github.io/mia-muse-assets/mia-teaches-v2-talorys-final.mp4
- `mia-teaches-v2-axuse-final.mp4` — Accessibility-tree browser agent tooling: agents see real page structure, not screenshots. https://mohammedabdelshafy.github.io/mia-muse-assets/mia-teaches-v2-axuse-final.mp4
- `mia-teaches-v2-soma-final.mp4` — Describe-it-print-it CAD: describe the part, get code, rebuild the 3D model, export and print. https://mohammedabdelshafy.github.io/mia-muse-assets/mia-teaches-v2-soma-final.mp4
